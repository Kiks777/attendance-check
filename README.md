# Attendance Check

Attendance Check is a barcode-based attendance tracking application developed during second year as a final project for Application Development. It is designed to simplify attendance recording during events by scanning existing student ID barcodes.

## Features
- Barcode-based attendance scanning using student ID barcodes  
- Fast and efficient attendance recording during events  
- Simple and user-friendly interface  

## Design
- Designed using Figma  

## Development
- Developed using Android Studio  

## Project Type
- Second Year Final Project for Application Development
